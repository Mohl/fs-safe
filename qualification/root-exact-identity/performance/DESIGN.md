# Root exact identity domain v2 — frozen source-only design

Eight row/mode cells are sufficient for this bounded simplification. Native off measures construction, public `Root.resolve` (the changed assertion path), nested stat, a 16-name list, and complete ordinary 16-file walks with `skip` and `include`. Require repeats only nested stat and list, whose production traversal can call `observeDirectory`. The include walk child branch calls the shared resolver without a native directory observer. Construction, assertion and walk are explicitly JavaScript route checks, regardless of native configuration.

Every selected call is public and uses an installed consumer, with production environment and hooks absent. Fixtures are small, stable, real files and directories. A separate untimed witness wraps actual filesystem observations without changing their values and, for require, the actual selected consumer addon method; the original descriptors are restored before timing. Require stat/list must dispatch `observeDirectory`; addon loading or a mode flag alone is insufficient. All four consumers include the same explicitly installed, freshly pinned host-addon tarball, including off-mode consumers. Exact-filter instrumentation begins before consumer imports and records addon dlopen attempts; off must record zero and require must match the bound binary digest. Fresh functional readiness owns public equality and an inspected internal declaration allowlist; complete declaration equality is not imposed.

The fixed machinery from #766 is reused: 24 blocks, four independent consumer arms, 10 warmups, one checked call, and five sample means of 20 fully awaited calls. Off has six rows and require has two. Mode lane order alternates per block; the four existing balanced arm orders repeat six times independently in each lane. This gives 192 processes, 76,800 timed calls and 3,840 sample means. Process timeout is 180 seconds and campaign timeout is 2,700 seconds, including both modes. No repeat, dropped row, tuning, seed change, or replacement campaign is allowed to obtain acceptance.

Source and same-source control log-ratio bounds retain #766's df-23 critical value and 1.10 limit. Every source and control bound must pass. Failure to complete or validate is incomplete/HOLD; a completed regression or control failure is complete/HOLD. The raw elapsed journal and all partial evidence remain available, and sample means are reconstructed in original addition order. These are per-row sample-mean results, not individual request tails or a familywise confidence statement.
